## สิ่งที่ต้องทำเองก่อนส่ง

- **กรอกข้อความในวงเล็บเหลี่ยม** บนปกและปกในของ `report.docx` (ชื่อและรหัสนักศึกษาสองคน ชื่ออาจารย์ผู้สอน ชื่อรายวิชา และชื่อภาควิชา คณะ สถาบัน) และสไลด์แผ่นแรกของ `slides.pptx` ถ้าจะสร้างไฟล์ใหม่จากต้นฉบับ ให้กรอกที่บรรทัดบนสุดของ `REPORT_DRAFT.md` แทน

## โครงของรายงาน

รายงานจัดตามรูปแบบรายงานวิชาการ

| ส่วน | เนื้อหา | มาจากไหน |
| --- | --- | --- |
| ปกหน้า กระดาษรองปก ปกใน | ชื่อเรื่อง ผู้จัดทำ ผู้สอน รายวิชา | บรรทัด `ชื่อ: ค่า` บนสุดของ `REPORT_DRAFT.md` |
| คำนำ บทคัดย่อ | เลขหน้าเป็นตัวอักษรไทย (ก ข ค) | หัวข้อ `## คำนำ` และ `## บทคัดย่อ` |
| สารบัญ สารบัญรูป สารบัญตาราง | สร้างอัตโนมัติ | หัวข้อ, บรรทัดรูป `![รูปที่ ...]` และบรรทัด `**ตารางที่ ...**` |
| บทที่ 1 ถึง 5 | บทนำ · เอกสารและงานวิจัยที่เกี่ยวข้อง · วิธีดำเนินการศึกษา · ผลการวิเคราะห์ข้อมูล · สรุปผล อภิปรายผล และข้อเสนอแนะ | หัวข้อ `## บทที่ N ...` |
| บรรณานุกรม | รูปแบบ APA หนึ่งย่อหน้าต่อหนึ่งรายการ | หัวข้อ `## บรรณานุกรม` |
| ภาคผนวก ก ถึง จ | การตั้งค่าของทุกโมเดล ตารางเพิ่มเติม หลักฐานการเปิด Test, ง การทดลอง RBF Kernel Perceptron หลังส่งงาน, จ การทดลอง transfer learning หลังนำเสนอ | หัวข้อ `## ภาคผนวก ...` |

กติกาของต้นฉบับ: รูปและตารางใช้เลขตามบท เช่น รูปที่ 3.1 และตารางที่ 4.2 ทุกตารางต้องมีบรรทัด `**ตารางที่ X.Y** คำอธิบาย` อยู่เหนือตาราง ถ้าไม่มี สคริปต์จะหยุดพร้อมบอกว่าตารางไหนขาด เมื่อเพิ่มหรือลบรูปและตาราง ต้องไล่เลขและการอ้างถึงในเนื้อหาเอง

## แก้รายงานอย่างไร

มีสองทาง เลือกทางใดทางหนึ่ง

**ทางที่ 1: แก้ใน Word โดยตรง** เปิด `deliverables/report.docx` แล้วแก้ได้เลย เหมาะกับการแก้สำนวนหรือจัดหน้าเล็กน้อย ข้อเสียคือถ้าสร้างไฟล์ใหม่จากต้นฉบับ การแก้ใน Word จะหายไป

**ทางที่ 2: แก้ที่ต้นฉบับแล้วสร้างใหม่** เหมาะเมื่อตัวเลขเปลี่ยนหรือแก้เนื้อหามาก

```bat
rem 1. แก้ docs\report\REPORT_DRAFT.md (ห้ามแก้ตัวเลขในตารางระหว่าง BEGIN GENERATED กับ END GENERATED)

rem 2. เติมตารางจากไฟล์ผล
.\.venv\Scripts\python.exe -m src.ml.docs_sync

rem 2.1 ถ้า notebook 04/05 เปลี่ยน ให้บันทึกรูปของภาคผนวก ง และ จ จาก output ของ notebook ใหม่
.\.venv\Scripts\python.exe docs\report\tools\export_notebook_figures.py

rem 3. สร้างไฟล์ Word (ต้องมี Node.js; ติดตั้ง library ครั้งแรกครั้งเดียว)
cd docs\report\tools
npm install docx
node build_docx.js ..\..\.. ..\..\..\deliverables\report.docx
cd ..\..\..

rem 4. ให้ Word อัปเดตสารบัญและส่งออก PDF (ต้องมี Microsoft Word; ใช้ path เต็ม)
powershell -File docs\report\tools\word_finish.ps1 -DocxPath "%CD%\deliverables\report.docx" -PdfPath "%CD%\deliverables\report.pdf"
```

`build_docx.js` รองรับ Markdown เฉพาะส่วนที่รายงานใช้: หัวข้อ, ย่อหน้า, รายการ, ตาราง, รูป, blockquote, ตัวหนา (`**...**`) และ code (`` `...` ``) ตารางที่กว้างจะถูกวางบนหน้าแนวนอนโดยอัตโนมัติ ตัวหนากับ code ซ้อนกันไม่ได้ และหัวข้อภาษาอังกฤษที่มากับตารางที่สร้างอัตโนมัติจะไม่ถูกพิมพ์ลงในไฟล์ Word เพราะใช้คำบรรยายตารางภาษาไทยแทน
