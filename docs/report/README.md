| ส่วน | เนื้อหา | มาจากส่วนใดของต้นฉบับ |

การจัดหน้าใช้ฟอนต์ TH SarabunPSK ทั้งเล่ม เนื้อความขนาด 16 พอยต์ หัวข้อเป็นตัวหนาขนาด 17 ถึง 20 พอยต์ ข้อความทั้งหมดเป็นสีดำ ไม่มีแถบสีหรือการเน้นด้วยสี ระยะขอบกระดาษด้านบนและด้านซ้าย 1.5 นิ้ว ด้านล่างและด้านขวา 1 นิ้ว ตารางที่กว้างเกินหน้ากระดาษแนวตั้งจะถูกวางบนหน้าแนวนอนซึ่งมีระยะขอบ 1 นิ้วทุกด้าน อักษรกรีกและสัญลักษณ์ทางคณิตศาสตร์ที่ฟอนต์ TH SarabunPSK ไม่มี จะพิมพ์ด้วยฟอนต์ Cambria หรือ Segoe UI Symbol ในขนาดที่เล็กลงให้เข้ากับตัวอักษรรอบข้าง

กติกาของต้นฉบับมีดังนี้ รูปและตารางใช้เลขตามบท เช่น รูปที่ 3.1 และตารางที่ 4.2 ทุกตารางต้องมีบรรทัด `**ตารางที่ X.Y** คำอธิบาย` อยู่เหนือตาราง ถ้าไม่มี สคริปต์จะหยุดและแจ้งว่าตารางใดขาดคำบรรยาย เมื่อเพิ่มหรือลบรูปและตาราง ต้องไล่เลขและการอ้างถึงในเนื้อหาใหม่เอง

## วิธีแก้รายงาน

แก้ได้สองวิธี

วิธีแรกคือแก้ใน Word โดยตรง โดยเปิด `deliverables/report.docx` แล้วแก้ได้ทันที วิธีนี้เหมาะกับการแก้สำนวนหรือจัดหน้าเล็กน้อย แต่ถ้าสร้างไฟล์ใหม่จากต้นฉบับภายหลัง การแก้ใน Word จะหายไป

วิธีที่สองคือแก้ที่ต้นฉบับแล้วสร้างไฟล์ใหม่ วิธีนี้เหมาะเมื่อตัวเลขเปลี่ยนหรือแก้เนื้อหาจำนวนมาก

```bat
rem 1. แก้ docs\report\REPORT_DRAFT.md (ห้ามแก้ตัวเลขในตารางที่อยู่ระหว่าง BEGIN GENERATED กับ END GENERATED)

rem 2. เติมตารางจากไฟล์ผล
.\.venv\Scripts\python.exe -m src.ml.docs_sync

rem 3. ถ้า notebook 03, 04 หรือ 05 เปลี่ยน ให้บันทึกรูปที่รายงานใช้จาก output ของ notebook ใหม่
.\.venv\Scripts\python.exe docs\report\tools\export_notebook_figures.py

rem 4. สร้างไฟล์ Word (ต้องมี Node.js และติดตั้ง library ครั้งแรกเพียงครั้งเดียว)
cd docs\report\tools
npm install docx
node build_docx.js ..\..\.. ..\..\..\deliverables\report.docx
cd ..\..\..

rem 5. ให้ Word ปรับสารบัญและส่งออก PDF (ต้องมี Microsoft Word และใช้ path เต็ม)
powershell -File docs\report\tools\word_finish.ps1 -DocxPath "%CD%\deliverables\report.docx" -PdfPath "%CD%\deliverables\report.pdf"
```

`build_docx.js` อ่าน Markdown เฉพาะส่วนที่รายงานใช้ ได้แก่ หัวข้อ ย่อหน้า รายการ ตาราง รูป blockquote ตัวหนา (`**...**`) และ code (`` `...` ``) ตัวหนากับ code ซ้อนกันไม่ได้ หัวข้อภาษาอังกฤษที่มากับตารางที่สร้างอัตโนมัติจะไม่ถูกพิมพ์ลงในไฟล์ Word เพราะใช้คำบรรยายตารางภาษาไทยแทน

ภาษาไทยไม่มีการเว้นวรรคระหว่างคำ ถ้าเครื่องที่เปิดไฟล์ไม่ได้ติดตั้งภาษาไทยสำหรับการแก้ไขใน Office โปรแกรม Word จะตัดบรรทัดได้เฉพาะที่ช่องว่าง สคริปต์จึงแทรกอักขระ zero-width space ที่ขอบเขตของคำไทยทุกคำ โดยใช้ตัวตัดคำ `Intl.Segmenter` ของ Node.js อักขระนี้มองไม่เห็นและไม่เปลี่ยนเนื้อความ แต่ทำให้ Word ตัดบรรทัดตรงขอบคำและจัดย่อหน้าแบบกระจายแบบไทยได้
